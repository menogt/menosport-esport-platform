START HERE
==========

This is a React + Vite project. Do NOT open index.html directly.

To run on Windows:
1. Extract the zip.
2. Double-click RUN_WINDOWS.bat.
3. Open the localhost URL shown in the terminal.

Manual run:

npm install
npm run dev
